### マージなしの自動実行（Autopilot-stack）

マージまでの自動実行（Autopilot-full）のプレイブックを実行する。ただし、マージはしない。

1. **手順 5 の代わりに、検証済みの時点で止まる。** 各 PR が現在の head で検証済みになり、CI が通ったら止まり、PR をオペレーターに引き渡す。引き渡したあとは、オペレーターの許可なしに誰も push しない。ループの各回のプロンプトにはこのファイルを書き、どの回もマージしないという規則を読めるようにする。
2. **PR を積み重ねるのは、それが別の PR の上に作られるときだけにする。** これは手順 3 の唯一の例外である。`playbooks/opening-a-pr.md` に従い、その PR のベースを trunk ではなく別の PR のブランチにする。手順 2 の trunk へのリベースの代わりに、各 PR は親の PR のブランチにリベースし、スタックの根元の PR は trunk にリベースする。下の PR に新しい head ができたら、その上の PR を積み直す。積み直しで `git patch-id` が変わらなかった PR は、判定をそのまま保つ。

**返答。** マージしたものの代わりに、各 PR とその判定を挙げる。
