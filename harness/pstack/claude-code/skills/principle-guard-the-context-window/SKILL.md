# コンテキストウィンドウを守る（Guard the Context Window）

**理由:** コンテキストがあふれると、推論の質が落ち、圧縮による歪みが生じ、作業が止まる。

**パターン:**
- **フェーズの大きさを決め、範囲に上限を設ける。** フェーズごとのファイル数を制限し、ターン数の予算を決め、仕組みそのもののコストも勘定に入れる。
