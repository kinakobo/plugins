# なぜ（Why）

コードではなく記録から答える。対象を導入したコミットと PR の議論、およびその後の各変更のコミットと PR の議論を読み、記録が乏しければほかの情報源も読む。作者が書いたことを引用し、自分の推論は推論だと明記し、記録からは答えが出ないことを述べる。
