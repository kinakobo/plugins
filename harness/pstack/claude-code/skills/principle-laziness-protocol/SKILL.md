# 怠惰のプロトコル（Laziness Protocol）

- **判断を 1 か所にまとめる。** 同じ選択を複数の場所で繰り返さない。判断を 1 つの信頼できる情報源（source of truth）に集め、その結果を単純なフラグとして渡す。
- **diff を最小にする。** 問題を解決する最小の変更をする。行数が少ないほうが、「エレガントな」ボイラープレートに勝る。
